# Number Guessing Game
This is a simple python project , where a number from 1-100 is picked at random by python and the user has to guess it in least number of attempts.

## FEATURES
- Random number generator using random module
- High Score and number of attempts track and display
- Saves High Score in file

## HOW TO RUN THE GAME:
Run main.py using python 

## Files
- main.py → main game logic
- high_score_tracker.py → handles score saving/loading
- high_score.txt → stores best score
